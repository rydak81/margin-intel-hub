## Correctness and access repairs

- Round minimum selling prices upward to the nearest cent so rounding cannot put the achieved margin below its target. Include minimum referral charges in both forward and reverse calculations.
- Reject invalid costs, rates, fee tiers and CSV dates. Validate stored browser settings and tolerate unavailable browser storage.
- Parse Keepa Buy Box history as time/price/shipping triplets. Field 32 is used-condition pricing, not unit sales. Read `monthlySoldHistory` separately and label Amazon purchase ranges as lower bounds. Preserve unavailable-price markers and carry forward unchanged price observations.
- Exclude generated examples and purchase ranges from sales forecasts. Exact price/units observations are required; this release does not provide an exact-sales import. No validated demand forecast is claimed.
- Mark the August 5, 2026 catalog as historical examples, fee schedules as unverified assumptions, and sample histories as illustrative. Keepa New-condition data is not directly comparable to the Renewed catalog.
- Optional paid lookups require all three server variables: `REPRICER_KEEPA_ENABLED=true`, `KEEPA_API_KEY`, and comma-separated trusted Supabase user IDs in `REPRICER_KEEPA_USER_IDS`. Validate each user with `auth.getUser()` and reject anonymous accounts.
- Both data endpoints return private/no-store responses. Provider reads have a 10-second timeout, bounded per-instance caches and request deduplication. A six-requests/minute per-user per-instance throttle is supplementary protection, not a global spending cap. Keep the allowlist restricted to trusted operators.
- Manual pricing and sample charts work without credentials. No paid requests, production environment changes, or new data subscriptions were used during verification.
